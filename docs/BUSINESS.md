# LessonDesk 业务范围

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2

单经营主体、多分校按组织隔离。学员绑定独立登录账号，购买分钟制课时套餐并人工核实足额收款后预约。每次一名学员、一名教练、一辆教练车，核对类别、启停、工作窗口、请假/检修、缓冲和时间占用。课时使用预留和核销双账，取消和改期按购买时快照规则；教师登记授课记录，不是官方驾考认证。

BOOKED → ARRIVED → LIVE → DONE。取消/缺席是终态；允许管理员说明理由豁免取消扣时，学员取消按冻结规则计时。完成只能核销预留以内的实际分钟；不足部分释放。已执行课次不删改，修正新增有审计依据的课程记录不回写原单。停课前需取消所有未完成预约；按已核销分钟的套餐价值向上取整计算不退金额，剩余可退金额按原收款逐笔退。所有收退款均是凭据核实后的不可变台账，不发起银行卡扣款。

时间存UTC、在浏览器时区展示，工作时间显式发布一次性窗口；不提供周期自动排课、地图动态通勤、政府学时/驾考接口、短信、支付网关、原生App或多公司SaaS。公网询盘仅新增私有记录，不发送外部消息。
